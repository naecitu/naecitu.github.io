# Naecitu · Seven Mixto

Página pública del torneo Naecitu (Club San Fernando): inscripción de equipos, entradas para la fiesta, fixture, posiciones y paneles de organización.

- La página es estática y se publica con GitHub Pages.
- Los datos, los mails y los comprobantes viven en Google (Apps Script + Google Sheets de la cuenta del torneo). La página les habla a través de la URL definida en `API_URL` dentro de `index.html`.
